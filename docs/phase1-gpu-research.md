## cgpu local reproduction and actual blocker

```sh
cd /home/abdullah/Downloads/Tools
export PATH="/home/abdullah/.nvm/versions/node/v24.16.0/bin:$PATH"
# Already installed locally; this re-creates it after an ignored-runtime cleanup.
npm install --prefix .runtime/cgpu --ignore-scripts --no-fund --no-audit --save-exact cgpu@0.1.4
node .runtime/cgpu/node_modules/cgpu/dist/src/index.js --help
```

The CLI requires operator-owned Google OAuth client configuration and account consent for Colab. Do not paste OAuth credentials into chat or commit a config. No local NVIDIA CLI was present, and no usable local GPU was verified. CLI installation is not GPU provisioning.

Google’s [official Colab FAQ](https://research.google.com/colaboratory/faq.html) prohibits unrelated media/web services and restricts remote shells, UI bypasses and distributed workers on free managed runtimes. GPU capacity is not guaranteed. We will not attach Toolroom’s public job queue to these free sessions or bypass restrictions. Use a provider-supported GPU host or local compatible GPU under its terms; existing CPU-capable MODNet/Swin2SR workers remain prepared and disabled in production.

The isolated install emitted deprecated dependency warnings. Its audit reports one Zod memory-exhaustion advisory (GHSA-mrhx-c7xc-m3w5), propagated as two high-severity package entries (zod and cgpu); cgpu pins Zod 3.23.8 and npm reports no automatic compatible fix. Keep this CLI outside Toolroom and do not give it account credentials or expose its server until an upstream-compatible patched release is reviewed. Help/config-failure checks are not runtime security acceptance. No cgpu dependency was added to package-lock.json or a public route. Any future personal learning session needs its own account/policy check; no authentication was attempted against an existing account.
